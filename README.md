# 回声 — 让每一次选择，都回应未来的自己

> 一个帮你「向后复盘」的决策记录工具 —— 不是帮你做决定，而是帮你验证自己到底会不会做决定。

## 这是什么

大多数效率工具都帮你**向前规划**：列目标、排日程、做待办。回声反过来，它帮你**向后复盘**。

每一次你面临选择（选了 A 还是 B），把当时的情况、你的把握、最后的结果记下来。过一段时间回来翻，你会看见一个扎心的真相：

- 你以为有把握的事，结果未必好；
- 你犹豫再三的事，往往只是拖着没做；
- 同一个坑（冲动消费、为「未来的我」买单），你会反复踩。

这就是「回声」的意义 —— 把选择的质量变得**可被看见、可被纠正**。

## 为什么做

我们每天都在做选择，却很少回头验证选择的质量。

种子数据来自一名**嵌入式专业大一学生**的真实经历：去哪所大学、去不去深圳实习、要不要把心里话说出口、618 又囤了什么没用的配件……这些带着毛边的抉择，比精致的示例更有说服力。

## 它能做什么

- **记录抉择**：用「选了 A / 没选 B」的结构化表单，记下情况、预期、结果、复盘与当时的信心。
- **画廊与时间线**：按卡片或全局时间轴浏览所有抉择，支持搜索、筛选、对比。
- **洞察生成器**：自动从你的记录里提炼三类洞察（信心校准 / 关注方向 / 复盘习惯），点结论可**下钻**到对应抉择。
- **回声定位**：强调「复盘」而非「规划」，差异化于「向前引导」类效率产品。
- **数据可迁移**：支持导出 / 导入 JSON（带字段白名单校验，安全）。

## 评委怎么玩

1. 打开画廊，翻翻这些带着毛边的真实抉择；
2. 点「创建」亲手记一条自己的选择；
3. 去「洞察」页看图表，点结论能下钻到对应抉择；
4. 「关于」页讲清了它和「向前引导」类产品的差异。

## 技术栈

- 单文件应用：Vue 3（CDN）+ Tailwind CSS（CDN）+ 原生 localStorage
- 图表：Chart.js 4.4
- 平滑滚动：Lenis
- 零构建、零依赖安装，双击 `index.html` 即可运行

## 运行

直接用浏览器打开 `index.html` 即可。数据保存在浏览器 localStorage，首次打开会自动种入示例数据。

## 设计语言

暖琥珀暮色 + 深色玻璃拟态：落日橙的暖炭背景、琥珀主色 `#C47B4B`、液体玻璃与潮汐呼吸的微交互，刻意避开「AI 蓝紫」的套路感。
