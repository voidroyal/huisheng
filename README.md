# 回声 — 让每一次选择，都回应未来的自己

> 一个帮你「向后复盘」的决策记录工具 —— 不是帮你做决定，而是帮你验证自己到底会不会做决定。
> **在线体验**：https://echo-alpha-wine.vercel.app/

## 这是什么

大多数效率工具都帮你**向前规划**：列目标、排日程、做待办。回声反过来，它帮你**向后复盘**。

每一次你面临选择（选了 A 还是 B），把当时的情况、你的把握、最后的结果记下来。过一段时间回来翻，你会看见一个扎心的真相：

- 你以为有把握的事，结果未必好；
- 你犹豫再三的事，往往只是拖着没做；
- 同一个坑（冲动消费、为「未来的我」买单），你会反复踩。

这就是「回声」的意义 —— 把选择的质量变得**可被看见、可被纠正**。产品名即隐喻：选择在当时落下，后来回来回应你。

## 为什么做

我们每天都在做选择，却很少回头验证选择的质量。

种子数据来自一名**嵌入式专业大一学生**的真实经历，共 11 条带毛边的抉择：去哪所大学、去不去深圳实习、要不要把心里话说出口、618 又囤了什么没用的配件……其中最有说服力的是一条**反差样例**：信心拉到 9 分去冲大创选题，结果被评委以"落地性不足"毙掉——复盘里写着"我把自信当成了事实"。高信心不是胜率，这正是回声要帮你看见的东西。

## 它能做什么

- **记录抉择**：用「选了 A / 没选 B」的结构化表单，记下情况、预期、结果、复盘与当时的信心。
- **画廊与时间线**：按卡片或全局时间轴浏览所有抉择，支持搜索、筛选、对比；时间线节点 **hover 即显标题**，不打断浏览。
- **洞察生成器**：自动提炼三类洞察（信心校准 / 关注方向 / 复盘习惯），点结论可**下钻**到对应抉择；边角**统计面板**实时显示总条数 / 高信心 / 预期偏差。
- **冷暖双主题**：暖琥珀（默认）与冷蓝灰一键切换，全部组件、图表、背景暮色同步换色，选择自动记住。
- **首次引导**：打开即弹出产品介绍；画廊/洞察首屏有「你在看什么」引导行；金句卡「你只管选，时间负责批改。」
- **数据可迁移**：一键导出全部记录为 JSON 备份（支持导入，带字段白名单校验，安全）。
- **空状态友好**：删光记录后给出引导，一键跳转新建。

## 评委怎么玩

1. 走「此路彼路」，翻翻这 11 条带着毛边的真实抉择，点开反差样例看复盘落差；
2. 点「新建抉择」亲手记一条自己的选择；
3. 去「回望岔口」看图表，点结论下钻到对应抉择，再点点边角的统计面板；
4. 点导航「暖色/冷色」切主题，刷新看看选择被记住；
5. 「关于」页讲清了它和「向前引导」类产品的差异。

## 技术栈

- 单文件应用：Vue 3（CDN）+ Tailwind CSS（CDN）+ 原生 localStorage
- 图表：Chart.js 4.4.1（散点 / 环形 / 柱状，含点击下钻）
- 平滑滚动：Lenis 1.1.14；标题衬线：霞鹜文楷
- 零构建、零依赖安装，双击 `index.html` 即可运行

## 运行

直接用浏览器打开 `index.html` 即可。数据保存在浏览器 localStorage，首次打开会自动种入 11 条示例数据（已勾选过弹窗或想重看种子，清一次 `destiny_crossroads_v1`）。

## 设计语言

深色玻璃拟态 + **冷暖双主题**（CSS 变量驱动，全部色值 token 化）：

- **暖琥珀**：落日橙暖炭背景、琥珀主色 `#C47B4B`、液体玻璃与潮汐呼吸微交互；
- **冷蓝灰**：钢蓝 `#6E9EC7` + 蓝灰玻璃，同一产品两种气质；
- 刻意避开「AI 蓝紫」的套路感，像一本有温度的手账，而不是一个效率面板。
